# 👗 AI-Powered AR/VR Fashion Stylist

An intelligent cross-platform AR/VR fashion application that enables users to virtually try on clothes, accessories, makeup, and footwear using Augmented Reality and Virtual Reality. The application integrates Artificial Intelligence for personalized fashion recommendations and voice assistance to create an immersive shopping experience.

---

## 📌 Project Overview

Traditional online shopping often makes it difficult for users to visualize how fashion products will look before purchasing. This project addresses that challenge by providing an interactive AR/VR platform where users can virtually try on fashion products while receiving AI-powered styling suggestions and voice-guided assistance.

---

## ✨ Features

- 👕 Virtual Try-On for Clothes
- 👜 Virtual Try-On for Accessories
- 💄 Virtual Makeup Preview
- 👟 Virtual Footwear Try-On
- 🤖 AI Personal Fashion Stylist
- 🎤 Voice Commands (Speech-to-Text)

- ❤️ Wishlist & Shopping Cart
